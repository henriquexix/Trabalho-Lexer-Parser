Projeto desenvolvido em Python utilizando a biblioteca SLY. Baseado na Linguagem Julia.

Funcionalidades implementadas
- Atribuição
- println()
- IF simples com comparação
- FOR com intervalo

## Estrutura do projeto

```text
projeto_julia
├── main.py
├── parser.out
├── core
│   ├── lexer.py
│   └── parser.py
└── examples
```

## Como executar

```bash
python main.py
```
